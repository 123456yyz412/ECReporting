# ECReporting

一款前后端分离的报表与数据填报 Web 应用：
- 后端：Django + DRF（JWT 鉴权）
- 前端：Vue3 + Vite + Element Plus
- 应用元数据：PostgreSQL（兼容 15-18）
- 数据源实例：PostgreSQL / MySQL

## 功能概览

- 人员权限管理：管理员/普通用户，基于用户组授权
  - 用户组管理：创建、修改、删除
  - 用户管理：创建、修改、删除，至少加入一个用户组，可以添加多个用户组
- 模块分级：
  - 报表模块（一级）：集合（相当于二级模块）→ 查询/看板
  - 数据填报模块（一级）：上传模块（相当于二级模块）
- 数据报表：
  - SQL 查询（仅允许 SELECT/WITH）
  - 查询可配置可视化（ECharts）
  - 看板可拼接多个查询组件（拖拽/缩放）
  - SQL 隐藏：隐藏后仅管理员/集合创建者/查询创建者可查看与编辑 SQL
- 数据填报：
  - 下载表模板（CSV/XLSX，表头两行：英文名/中文名）
  - 上传 CSV/XLSX 入库
- 商品管理：
  - SKU管理：
    - SKU 创建、修改、删除，管理员自定义属性(例如：分类、颜色、尺寸)，自动生成SKU
    - SKU 信息和映射关系：SKU 映射关系表，创建SKU时自动生成，可以下载
    - SKU 分级：一级分类、二级分类、三级分类
    - SKU 标签：精品、新品、爆款、热门、推荐
  - 基础管理
    - 商品分级：精品商品、新品商品、一级商品、二级商品、三级商品
    - 商品编码：SKU 编码、货号、条形码、SPU 编码
    - 商品基础信息：名称、副标题、卖点、简介、详情页、图片
    - 商品新增 / 编辑 / 复制 / 下架 / 删除 / 批量操作（RPA操作ERP系统或者web自动化脚本、有接口通过接口获取数据，可以上传脚本自定义，实现触发脚本和校验操作）
      - 脚本ID下拉框或者脚本名称两个筛选框，指定关联脚本
- 业务培训：
  - 数据看板：考试结果看板
  - 题库管理：管理题库
  - 考试管理：管理考试，创建考试，查看考试结果，可以查看每次考试每个人试卷
  - 试卷管理：管理试卷，创建试卷，查看试卷结果，可以查看每次考试每个人试卷
  - 知识库：管理知识库，能上传文件到知识库中
    - 知识库看板
    - 文档管理：能建立文件夹，上传文件到文件夹中，下载文件，删除文件，查看文件，权限通过指定用户组管理
- 自动化脚本：通过创建脚本模块，粘贴进自动化脚本，然后运行脚本。
  - 脚本模块：创建脚本，删除脚本，自定义脚本名称(唯一性)，自动生成脚本模块ID，有运行按钮和定时功能。
- AI决策中心:
  - 行业百晓生(新闻分析)：搜集目标国家新闻，进行新闻分类，进行新闻内容分析，词频统计，预测趋势。
  - 库存分析助手：库存预测，库存分析，库存预警，输出库存备货计划
  - 业务总助：分析公司业务，业绩监控，分析库存
  - 自定义Agent: 点击+号，可以创建类似上述Agent,上述有特定开发的页面和精美布局，这里以对话框实现。
  - 设置：
    - 模型配置：自定义配置几种模型
- 流程引擎：
  - 流程定义：创建流程定义，创建流程实例，查看流程实例，查看流程任务，处理流程任务，结束流程实例。
